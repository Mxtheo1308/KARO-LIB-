# 🚗 KAR'O LIB

## Projet étudiant — Mobilité à La Réunion

**KAR'O LIB** est un concept de service de voitures sans permis électriques en libre-service à La Réunion.

L'objectif du projet est d'imaginer une solution de mobilité simple pour les trajets courts : trouver un véhicule, le réserver, effectuer son trajet puis le restituer dans une station autorisée.

## 🌴 Fonctionnalités

* 🏠 Présentation du concept
* 📍 Présentation des stations pilotes
* 💶 Exemple de tarifs
* 📋 Sondage auprès des utilisateurs
* 📱 Site adapté aux téléphones et ordinateurs
* 🌐 Compatible avec GitHub Pages

## 🗺️ Stations pilotes

La carte présente des emplacements conceptuels à La Réunion.

> Les emplacements présentés sont fictifs et devront être validés par une étude réelle.

## 💰 Tarifs proposés

Les tarifs affichés sur le site sont fictifs et servent uniquement à illustrer le projet :

* **0,25 € / minute**
* **-40 % pour les moins de 25 ans**
* **9,90 € / mois** pour un abonnement

Ces tarifs pourront être modifiés après une étude économique.

## 📊 Sondage

Le site contient un formulaire permettant de recueillir les avis des utilisateurs sur :

* leur intérêt pour le service ;
* le prix qu'ils seraient prêts à payer ;
* les zones où ils aimeraient trouver une station ;
* leurs remarques et suggestions.

Les informations personnelles inutiles ne doivent pas être communiquées dans le formulaire.
